One line, one autocorrect fail: a text to Mom where "promoted" came out as "pregnant".

> Mom, I got the results back — I'm pregnant! Sorry, I meant promoted. Please don't tell Dad yet.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
